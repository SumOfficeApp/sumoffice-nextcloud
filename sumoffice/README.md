# SumOffice Office — Nextcloud app

Points Nextcloud Office (richdocuments) at your SumOffice server (SumSheet for .xlsx/.xlsm/.xlsb, SumDoc for .docx) with one field, checks discovery and capabilities, shows what the server offers.

Run the server stack in three steps: https://sumoffice.com/nextcloud

Requires Nextcloud Office to be installed. Licence: AGPL-3.0.
